# ReplicantOS v0.1.0

The first public ReplicantOS source release is a free, MIT-licensed,
self-hosted control plane for persistent AI agents.

## Included

- Multiple users, Replicants, channels, tasks, and timezone-aware schedules
- Codex, optional Claude Agent SDK, OpenCode, and Grok Build adapters behind one
  normalized durable run lifecycle
- Permission-checked chat, run history, approvals, cancellation, diagnostics,
  files, documents, and a masked allowlisted SQLite viewer
- A loopback-only production entrypoint, explicit first-owner setup, and an
  installable PWA with no telemetry enabled by default
- Deterministic synthetic launch media plus clean-archive privacy, dependency,
  vulnerability, SBOM, and browser-test evidence

## Install

Follow the
[`v0.1.0` operator guide](https://github.com/replicantos/replicantos/blob/v0.1.0/docs/INSTALLATION.md).
Provider runtimes and their host-native credentials are installed separately;
ReplicantOS does not bundle or persist provider credentials.

## Release disposition

The repository owner explicitly waived the two-independent-reviewer gate for
this release. No reviewer approvals are claimed. All automated release
invariants remain mandatory, and the published evidence manifest records the
disposition as `owner-waived`.
