# Security Policy

ReplicantOS `v0.1.0` is the current supported source release. ReplicantOS is self-hosted infrastructure; operators must review their own host, provider credentials, backups, and network perimeter before using it with sensitive data.

Report a suspected vulnerability privately to [admin@replicantos.com](mailto:admin@replicantos.com) with `SECURITY` in the subject. Once the public repository enables GitHub private vulnerability reporting, that channel is also appropriate. Do not open a public issue containing a vulnerability, credential, private log, or reproduction with sensitive data.

We aim to acknowledge a report within three business days, provide an initial assessment within seven days, and coordinate disclosure only after a fix or mitigation is available. Only the latest tagged `v0.1.x` release is eligible for a security fix; development branches and superseded tags are not supported deployments.
