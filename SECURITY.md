# Security Policy

ReplicantOS is under pre-release development. Do not expose a development build to the public internet or use it with sensitive data.

Report a suspected vulnerability privately to [admin@replicantos.com](mailto:admin@replicantos.com) with `SECURITY` in the subject. Once the public repository enables GitHub private vulnerability reporting, that channel is also appropriate. Do not open a public issue containing a vulnerability, credential, private log, or reproduction with sensitive data.

We aim to acknowledge a report within three business days, provide an initial assessment within seven days, and coordinate disclosure only after a fix or mitigation is available. During pre-release development, only the latest tagged release is eligible for a security fix; unreleased branches and older prereleases are not supported deployments.
